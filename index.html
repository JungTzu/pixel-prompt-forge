📜 專案規格書｜PIXEL PROMPT FORGE (8-Bit AI 繪圖靈感鍛造屋)

一、專案背景與發想動機

配合「文字與圖像生成的原理與實務」課程，許多初學者在接觸 Midjourney、Stable Diffusion 或 Gemini 生圖時，常遇到「腦中有畫面卻不知如何轉化為精準英文 Prompt」或「漏掉光影、鏡頭與構圖詞綴」的困境。因此設計這款結合復古 8-Bit 像素鐵匠鋪 RPG 元素的互動式 Prompt 鍛造工具，讓組合生圖提示詞就像在遊戲中鑲嵌魔法晶石一樣直覺有趣。

二、視覺風格與介面設計

  • 復古 8-Bit 像素美學：採用像素字體（Press Start 2P / DotGothic16）、階梯式像素邊框陰影、CRT 掃描線濾鏡與 RPG 等級經驗值狀態列。
  • 深淺色模式一鍵切換：支援「🌙 暗黑地下城模式（深紫黑配霓虹綠）」與「☀️ 晨光羊皮紙模式（復古米白配磚紅）」，並自動記憶使用者偏好。
  • 8-Bit 原生合成音效：利用 Web Audio API 即時合成復古方波音效（點擊、轉蛋、打鐵、升級），無須外部音檔即可運作，並附帶靜音開關。

三、核心互動功能規格

  • 六大維度詞綴矩陣：涵蓋主體角色、藝術畫風、光影天氣、鏡頭視角、色彩氛圍、負面排除詞，並支援使用者自訂新增中英詞綴。
  • 鍛造鐵砧與權重調整：可針對單一詞綴調整 0.6x～1.6x 權重，並切換 Midjourney (`--ar`、`--s`)、Stable Diffusion `(tag:weight)` 與通用自然語言三種模型語法。
  • 隨機靈感扭蛋與大師配方：提供一鍵隨機抽取各維度詞綴的拉霸功能，以及 5 組經典主題預設配方。
  • 即時 8-Bit 像素意境預覽畫布：以 HTML5 Canvas 根據所選詞綴即時繪製對應的像素風景與動態粒子，並支援合成下載「PNG 靈感配方小卡」。
  • 完整度診斷與寶箱收藏夾：自動計算 Prompt 結構完整度評分，並可將喜愛的配方存入 `localStorage` 本地寶箱、搜尋回填或匯出 JSON。
